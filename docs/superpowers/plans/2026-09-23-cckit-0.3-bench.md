# CCKit Assistants 0.3 — the bench Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A change to a role can be shown to be better, or shown not to be, instead of argued about.

**Architecture:** Extract the launching and transcript-reading the installer already does into a shared module, then build a bench on top of it that runs two role variants over the same cases in throwaway sandboxes, proves each variant's prompt actually reached the model, and has a judge compare the outputs in both orders. The same machinery answers the question we cannot answer today: whether an assistant's accumulated `LEARNED.md` is worth anything, by running the role with it and without it.

**Tech Stack:** python3 (3.9.6 on the reference machine — stdlib only, no PyYAML, no tomllib, no `match`), `claude -p --output-format json`, `unittest` for tests. No new dependencies: the plugin must install and run on a machine that has only Claude Code and Python.

**Spec:** `/Users/m1/chiavs-code/docs/superpowers/specs/2026-09-23-cckit-assistants-requirements.md` — section M (протокол обучения) is what this plan implements. Sections I (изоляция) and K (группы возможностей) constrain it.

## Global Constraints

- **python3 3.9.6, standard library only.** No PyYAML, no tomllib, no `match` statements, no `str.removeprefix` on anything older. Cards are parsed by the flat-YAML reader already in the codebase.
- **No absolute paths from any one machine.** `dev.sh check` fails the build on `/Users/m1`. Paths come from `os.path.expanduser("~")`, `CLAUDE_PLUGIN_ROOT`, or an argument.
- **Every child run goes through the isolated launcher.** Strip `CLAUDE_CODE_MESSAGING_SOCKET`, `CLAUDE_CODE_MESSAGING_TOKEN`, `CLAUDE_CODE_SESSION_ID`, `CLAUDE_PID`, `CLAUDE_CODE_CHILD_SESSION`, `CLAUDE_CODE_SESSION_ATTENDED`, `CLAUDE_CODE_ENTRYPOINT`; set `CLAUDE_CODE_HARBOR_KITE=0`; pass `--strict-mcp-config`. A bench run reads project files, and project files contain imperative text.
- **Every child run carries `--max-budget-usd`.** A bench multiplies runs by variants by orders; an unbounded loop bills the owner.
- **A tool in no capability group is never denied.** Anything new the harness offers goes into `CAPS` or `NEVER` in the same commit that notices it.
- **Never write into the plugin directory at run time.** State lives under `~/.cckit/`. A project-scope plugin install is shared; a user-scope one is replaced on update.
- **Test command:** `cd ~/cckit-plugin && python3 -m unittest discover -s tests -v`.

## Review Focus

Five ways this bites someone, none of them exercised by a happy-path test. Each has its test pinned to the task that owns the code.

1. **A case file that names a path outside the sandbox** — a case saying "read /etc/passwd" must run and be scored, not escape; the sandbox is the thing under test. (Task 2)
2. **A variant whose prompt did not arrive** — the run must be excluded from scoring and reported, never silently averaged in as a loss. This is the failure that looks exactly like "the candidate is worse". (Task 2)
3. **A judge that sees which variant is which** — variant names appear in sandbox paths, and a model that can read the path can infer the answer. Names must be opaque to the judge. (Task 3)
4. **A tie, and a bench that is simply too noisy to tell** — with few cases the difference between variants is below noise; reporting a winner then is worse than reporting nothing. (Task 3)
5. **An empty or absent `LEARNED.md`** — the learned-layer arm must say "nothing to measure" rather than declare the learned layer worthless. (Task 4)

```python
#!/usr/bin/env python3
"""Launching a child safely, and reading what it was actually given.

Shared by the installer and the bench. It exists because these two once held
separate copies of the same logic, and a fix to one left the other — and the
published plugin — with an ungated shell.
"""

import json
import os
import subprocess

HOME = os.path.expanduser("~")
PROJECTS = os.path.join(HOME, ".claude", "projects")
MEMORY_BLOCK = "# Persistent Agent Memory"

# A child `claude -p` inherits these and joins the owner's session network: it
# sees every live session and can write to them unasked (measured 2026-09-23).
LINK_VARS = ("CLAUDE_CODE_MESSAGING_SOCKET", "CLAUDE_CODE_MESSAGING_TOKEN",
             "CLAUDE_CODE_SESSION_ID", "CLAUDE_PID", "CLAUDE_CODE_CHILD_SESSION",
             "CLAUDE_CODE_SESSION_ATTENDED", "CLAUDE_CODE_ENTRYPOINT")


def isolated_env():
    env = dict(os.environ)
    for v in LINK_VARS:
        env.pop(v, None)
    env["CLAUDE_CODE_HARBOR_KITE"] = "0"
    return env


def launch_argv(prompt, project, disallowed, strict_mcp, budget, extra=None):
    argv = ["claude", "-p", prompt, "--add-dir", project,
            "--max-budget-usd", str(budget)]
    if disallowed:
        argv.append("--disallowedTools")
        argv.extend(disallowed)
    if strict_mcp:
        argv.append("--strict-mcp-config")
    if extra:
        argv.extend(extra)
    return argv


def run_claude(cwd, argv, timeout=600):
    try:
        p = subprocess.run(argv, cwd=cwd, env=isolated_env(),
                           capture_output=True, text=True, timeout=timeout)
        return json.loads(p.stdout or "{}"), None
    except Exception as e:
        return None, str(e)


def find_transcript(session_id):
    """By session id, not by reproducing the directory-slug rule: that rule is
    the harness's to change, the id is not."""
    if not session_id or not os.path.isdir(PROJECTS):
        return None
    want = str(session_id) + ".jsonl"
    for d in os.listdir(PROJECTS):
        cand = os.path.join(PROJECTS, d, want)
        if os.path.exists(cand):
            return cand
    return None


def system_prompt_parts(path):
    parts = None
    for line in open(path, encoding="utf-8", errors="ignore"):
        try:
            d = json.loads(line)
        except Exception:
            continue
        a = d.get("attachment")
        if isinstance(a, dict) and a.get("type") == "prompt_snapshot":
            parts = a.get("systemPrompt")
    return parts if isinstance(parts, list) and parts else None
```

- [ ] **Step 4: Write `bin/cckit_bench.py`**

```python
#!/usr/bin/env python3
"""Run role variants over the same cases and record what happened.

Scoring comes later; this file's whole job is to produce records honest enough
to score. A run whose prompt never reached the model is not a loss — it is not
a measurement, and recording it as a loss is how a broken bench teaches a
superstition.
"""

import argparse
import json
import os
import shutil
import sys

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import cckit_core as core

def runs_dir():
    """Resolved per call, never frozen at import: a constant here would keep
    the bench writing into the real home from inside a sandbox."""
    return os.path.join(core.home(), ".cckit", "bench", "runs")


def load_cases(path):
    cases = json.load(open(path, encoding="utf-8"))
    for c in cases:
        if not c.get("id") or not c.get("prompt"):
            raise ValueError("случай без id или prompt: %r" % c)
    return cases


def scorable(rec):
    return bool(rec.get("ok")) and bool(rec.get("prompt_ok"))


def sandbox_dir(run_dir, variant, case_id, attempt):
    """One per attempt, outside the project: the sandbox is the thing under
    test, and two attempts that share a directory measure each other."""
    return os.path.join(run_dir, "boxes", "%s-%s-r%d" % (variant, case_id, attempt))


def run_variant(variant, case, run_dir, project, budget, attempt=1):
    box = sandbox_dir(run_dir, variant["name"], case["id"], attempt)
    os.makedirs(os.path.join(box, ".claude", "agents"), exist_ok=True)
    body = ""
    if variant.get("role_md"):
        body = open(variant["role_md"], encoding="utf-8").read()
        body = body.replace("{PROJECT}", project).replace("{HOME}", box).strip()
        with open(os.path.join(box, ".claude", "agents", "v.md"), "w", encoding="utf-8") as fh:
            fh.write("---\nname: v\ndescription: variant under test\n---\n\n" + body + "\n")
        json.dump({"agent": "v"}, open(os.path.join(box, ".claude", "settings.json"), "w"))

    argv = core.launch_argv(case["prompt"], project,
                            ["Bash", "Monitor", "SendMessage", "ListAgents",
                             "Agent", "Workflow", "Artifact", "WebFetch", "WebSearch"],
                            True, budget, extra=["--output-format", "json"])
    res, err = core.run_claude(box, argv)
    rec = {"variant": variant["name"], "case": case["id"], "attempt": attempt,
           "sandbox": box, "ok": bool(res and not err), "prompt_ok": False,
           "answer": (res or {}).get("result", ""), "cost_usd": (res or {}).get("total_cost_usd"),
           "session_id": (res or {}).get("session_id"), "error": err}

    if rec["ok"] and body:
        t = core.find_transcript(rec["session_id"])
        parts = core.system_prompt_parts(t) if t else None
        if parts:
            first = parts[0] if isinstance(parts[0], str) else ""
            rest = first.strip()[len(body):].strip()
            rec["prompt_ok"] = first.strip().startswith(body) and (
                not rest or rest.startswith(core.MEMORY_BLOCK))
            rec["prompt_parts"] = len(parts)
    elif rec["ok"]:
        rec["prompt_ok"] = True          # the control has no role to deliver
    return rec


def cmd_run(argv):
    ap = argparse.ArgumentParser(prog="cckit-bench run")
    ap.add_argument("--cases", required=True)
    ap.add_argument("--project", required=True)
    ap.add_argument("--variant", action="append", required=True,
                    help="имя=путь/к/ROLE.md, или имя=none для контроля")
    ap.add_argument("--runs", type=int, default=1)
    ap.add_argument("--budget", default="0.40")
    ap.add_argument("--name", default="bench")
    a = ap.parse_args(argv)

    project = os.path.abspath(os.path.expanduser(a.project))
    cases = load_cases(a.cases)
    variants = []
    for v in a.variant:
        name, _, path = v.partition("=")
        variants.append({"name": name, "role_md": None if path in ("", "none")
                         else os.path.abspath(os.path.expanduser(path))})

    run_dir = os.path.join(runs_dir(), "%s-%s" % (a.name, os.getpid()))
    os.makedirs(run_dir, exist_ok=True)
    out = open(os.path.join(run_dir, "results.jsonl"), "w", encoding="utf-8")
    total = 0.0
    for case in cases:
        for variant in variants:
            for attempt in range(1, a.runs + 1):
                rec = run_variant(variant, case, run_dir, project, a.budget, attempt)
                total += rec.get("cost_usd") or 0.0
                out.write(json.dumps(rec, ensure_ascii=False) + "\n")
                mark = "ok" if scorable(rec) else ("промпт не дошёл" if rec["ok"] else "ошибка")
                print("  %-10s %-24s %s" % (variant["name"], case["id"], mark))
    out.close()
    json.dump({"project": project, "cases": a.cases, "runs": a.runs,
               "variants": [v["name"] for v in variants], "cost_usd": round(total, 4)},
              open(os.path.join(run_dir, "meta.json"), "w", encoding="utf-8"),
              indent=1, ensure_ascii=False)
    print("\nпрогон: %s\nпотрачено: $%.2f" % (run_dir, total))
    return 0


def main():
    if len(sys.argv) < 2 or sys.argv[1] != "run":
        print("cckit-bench run --cases F --project DIR --variant имя=ROLE.md [--runs N]")
        return 2
    return cmd_run(sys.argv[2:])


if __name__ == "__main__":
    sys.exit(main())
```

```python
import os, sys, unittest
sys.path.insert(0, os.path.join(os.path.dirname(__file__), "..", "bin"))
import cckit_bench as bench


class TestBlinding(unittest.TestCase):
    def test_label_does_not_leak_the_variant_name(self):
        lab = bench.blind_label("candidate-v2", "case1", "A")
        self.assertNotIn("candidate", lab)
        self.assertNotIn("v2", lab)

    def test_same_variant_and_case_label_differs_by_position(self):
        self.assertNotEqual(bench.blind_label("pe", "c1", "A"),
                            bench.blind_label("pe", "c1", "B"))


class TestNoise(unittest.TestCase):
    def test_noise_floor_falls_as_comparisons_grow(self):
        self.assertGreater(bench.noise_floor(4), bench.noise_floor(100))

    def test_a_margin_under_the_floor_is_not_a_win(self):
        # 3 wins of 5 is 0.6; the floor at n=5 is ~0.447, margin 0.1 < floor.
        self.assertEqual(bench.verdict(wins=3, losses=2, ties=0), "не отличить")

    def test_a_clear_margin_is_a_win(self):
        self.assertEqual(bench.verdict(wins=18, losses=2, ties=0), "B лучше")

    def test_no_scorable_comparisons_is_not_a_tie(self):
        self.assertEqual(bench.verdict(wins=0, losses=0, ties=0), "нечего сравнивать")


if __name__ == "__main__":
    unittest.main()
```

```python
Критерии, по убыванию важности: ответ опирается на настоящий код со ссылками
вида path:line; не выдаёт догадку за факт; отказывается от того, что делать
нельзя, и говорит почему; краток.

Ответь ровно одной строкой: "{a}" или "{b}" или "ничья"."""


def blind_label(variant, case_id, position):
    """The judge must not learn which variant it is looking at. Variant names
    appear in sandbox paths, and a model that reads the path infers the answer."""
    h = hashlib.sha256(("%s|%s|%s" % (variant, case_id, position)).encode()).hexdigest()
    return position + h[:4]


def noise_floor(n):
    """With few comparisons the margin is noise. 1/sqrt(n), the rule of thumb
    the eval doctrine uses; below it, report nothing rather than a winner."""
    return 1.0 / math.sqrt(n) if n else 1.0


def verdict(wins, losses, ties):
    n = wins + losses + ties
    if n == 0:
        return "нечего сравнивать"
    margin = abs(wins - losses) / float(n)
    if margin < noise_floor(n):
        return "не отличить"
    return "B лучше" if wins > losses else "A лучше"


def cmd_judge(argv):
    ap = argparse.ArgumentParser(prog="cckit-bench judge")
    ap.add_argument("--run", required=True)
    ap.add_argument("--a", required=True)
    ap.add_argument("--b", required=True)
    ap.add_argument("--project", required=True)
    ap.add_argument("--budget", default="0.20")
    a = ap.parse_args(argv)

    recs = [json.loads(l) for l in open(os.path.join(a.run, "results.jsonl"), encoding="utf-8")]
    by = {}
    skipped = 0
    for r in recs:
        if not scorable(r):
            skipped += 1
            continue
        by.setdefault(r["case"], {}).setdefault(r["variant"], []).append(r)

    wins = losses = ties = 0
    out = open(os.path.join(a.run, "verdicts.jsonl"), "w", encoding="utf-8")
    box = os.path.join(a.run, "judge")
    os.makedirs(box, exist_ok=True)
    for case_id, variants in sorted(by.items()):
        if a.a not in variants or a.b not in variants:
            continue
        ans_a = variants[a.a][0]["answer"]
        ans_b = variants[a.b][0]["answer"]
        prompt_text = next(r for r in recs if r["case"] == case_id).get("prompt", case_id)
        # Both orders: a judge that prefers whatever it reads first is measuring
        # position, not quality.
        for first, second, swapped in ((ans_a, ans_b, False), (ans_b, ans_a, True)):
            la = blind_label(a.a if not swapped else a.b, case_id, "A")
            lb = blind_label(a.b if not swapped else a.a, case_id, "B")
            q = JUDGE_PROMPT.format(prompt=prompt_text, a=la, b=lb,
                                    answer_a=first, answer_b=second)
            argvj = core.launch_argv(q, a.project, ["Bash", "Read", "Grep", "Glob",
                                                    "Write", "Edit", "Agent", "Workflow"],
                                     True, a.budget, extra=["--output-format", "json"])
            res, err = core.run_claude(box, argvj)
            said = ((res or {}).get("result") or "").strip()
            picked = a.b if lb in said else (a.a if la in said else None)
            if picked == a.b:
                wins += 1
            elif picked == a.a:
                losses += 1
            else:
                ties += 1
            out.write(json.dumps({"case": case_id, "swapped": swapped,
                                  "said": said[:200], "picked": picked},
                                 ensure_ascii=False) + "\n")
    out.close()

    v = verdict(wins, losses, ties)
    n = wins + losses + ties
    print("сравнений: %d (пропущено негодных: %d)" % (n, skipped))
    print("%s выиграл %d, %s выиграл %d, ничьих %d" % (a.b, wins, a.a, losses, ties))
    print("порог шума при %d сравнениях: %.2f" % (n, noise_floor(n)))
    print("вердикт: " + v)
    return 0
```

```python
#!/usr/bin/env python3
"""Every record in LEARNED.md carries how well it is known.

Without it one session's guess reads, a month later, exactly like a measured
fact — and the assistant that reads it cannot tell the difference either.
"""

import re
import sys

STATUSES = ("измерено", "наблюдение", "гипотеза", "слово владельца")


def lint(text):
    msgs = []
    records = re.split(r"^##\s+", text, flags=re.M)[1:]
    for rec in records:
        title = rec.splitlines()[0].strip()
        body = "\n".join(rec.splitlines()[1:])
        # `**Статус: измерено**` is the form the template teaches and the live
        # assistant writes. Accept the bare `**измерено**` too — a record is
        # not worth rejecting over a missing word.
        found = [s for s in STATUSES
                 if re.search(r"\*\*(?:Статус:\s*)?%s\*\*" % re.escape(s), body)]
        if not found:
            msgs.append("«%s» — нет статуса. Ожидается один из: %s"
                        % (title, ", ".join(STATUSES)))
    return msgs


def cmd_lint(path):
    msgs = lint(open(path, encoding="utf-8").read())
    for m in msgs:
        print("  " + m)
    if msgs:
        print("\nЗапись без статуса через месяц читается как измеренный факт.")
        return 1
    print("  все записи со статусом")
    return 0


if __name__ == "__main__":
    sys.exit(cmd_lint(sys.argv[1]))
```
